## Что такое Java
Java - строго типизированный, объектно ориентированный язык программирования

Java - платформонезависимый язык программирование. в процессе разработки код разработчика преобразуется в байт-код который исполняется в Java Virtual Machine

JVM входит в состав Java Runtime Environment(JRE) - это пакет для запуска приложений для Java - кроме самой JVM в него входит еще стандартная библиотека Java-классов

для запуска приложений на Java достаточно JRE, но для разработки нам потребуется Java Development Kit(JDK), он включает в себя JRE и набор инструментов для разработки, например компиллятор javac
