
# Что такое Java

**Java** — строго типизированный, объектно-ориентированный язык программирования.

Java является **платформонезависимым** языком. Это означает, что исходный код, написанный разработчиком, компилируется не напрямую в машинный код, а в **байт-код**, который затем исполняется в **Java Virtual Machine (JVM)**.

**JVM** входит в состав **Java Runtime Environment (JRE)** — набора компонентов, необходимых для запуска Java-приложений. Помимо самой виртуальной машины, JRE содержит стандартную библиотеку Java-классов.

Для **запуска** Java-приложений достаточно JRE.  
Для **разработки** требуется **Java Development Kit (JDK)** — он включает в себя JRE и набор инструментов разработчика, например компилятор `javac`.

# Первое приложение на Java

Создаём новый проект.

Весь код на Java располагается в **классах** — текстовых файлах с расширением `.java`.

Создадим файл `FirstApp.java` и опишем класс:

```java
public class FirstApp {
}
```

Название класса **обязательно** должно совпадать с названием файла.

Теперь добавим главный метод программы:

```java
public static void main(String[] args) {
}
```

Внутри метода напишем первый код:

```java
System.out.println("Hello, world");
```

Теперь можно запустить приложение и увидеть результат в консоли.

# Типы данных

В Java существует два основных типа данных:

* **примитивные**
* **ссылочные**

## Примитивные типы

Примитивные типы делятся на четыре группы и включают **8 типов данных**:

1. **Целочисленные**: `byte`, `short`, `int`, `long`
2. **С плавающей точкой**: `float`, `double`
3. **Логический**: `boolean`
4. **Символьный**: `char`

| Тип данных | Размер (байт) | Диапазон значений                           | Значение по умолчанию | Пример               |
| ---------- | ------------- | ------------------------------------------- | --------------------- | -------------------- |
| byte       | 1             | -128 до 127                                 | 0                     | byte b = 100;        |
| short      | 2             | -32768 до 32767                             | 0                     | short s = 1000;      |
| int        | 4             | -2147483648 до 2147483647                   | 0                     | int i = 100000;      |
| long       | 8             | -9223372036854775808 до 9223372036854775807 | 0L                    | long l = 100L;       |
| float      | 4             | ±3.4E38 (6–7 знаков)                        | 0.0f                  | float f = 3.14f;     |
| double     | 8             | ±1.7E308 (15–16 знаков)                     | 0.0d                  | double d = 3.14159;  |
| char       | 2             | 0–65535 (Unicode)                           | '\u0000'              | char c = 'A';        |
| boolean    | 1             | true / false                                | false                 | boolean flag = true; |

Java — **строго типизированный** язык, поэтому при объявлении переменной необходимо указывать её тип:

```java
int x;
```

Примитивные типы **не могут быть `null`** — у них всегда есть значение.

Особенности:

* Для `long` используется суффикс `L`:

  ```java
  long x = 123L;
  ```
* Для `float` используется суффикс `F`:

  ```java
  float x = 123F;
  ```
* `char` хранит **один символ** в одинарных кавычках:

  ```java
  char c = 'A';
  ```
* `boolean` может принимать только `true` или `false`.

# Операции над примитивными типами

## Арифметические операции

| Оператор | Назначение         | Пример    | Результат        |
| -------- | ------------------ | --------- | ---------------- |
| +        | Сложение           | 5 + 3     | 8                |
| -        | Вычитание          | 5 - 3     | 2                |
| *        | Умножение          | 5 * 3     | 15               |
| /        | Деление            | 5 / 2     | 2 (целочисленно) |
| %        | Остаток от деления | 5 % 2     | 1                |
| ++       | Инкремент          | x++ / ++x | x + 1            |
| --       | Декремент          | x-- / --x | x - 1            |

Пример:

```java
int x = 1 + 1;
System.out.println(x);
```

Целочисленное деление:

```java
int x = 5 / 2; // 2
```

Оператор остатка от деления `%`:

```java
int a = 33;
int b = 5;
int c = a % b;  // 3
int d = 22 % 4; // 2
```

### Инкремент и декремент

Инкремент (`++`) увеличивает значение на 1,
декремент (`--`) уменьшает значение на 1.

**Префиксная форма** — сначала изменяет значение, потом использует:

```java
int a = 8;
int b = ++a;
System.out.println(a); // 9
System.out.println(b); // 9
```

**Постфиксная форма** — сначала использует значение, потом изменяет:

```java
int a = 8;
int b = a++;
System.out.println(a); // 9
System.out.println(b); // 8
```

Аналогично работает декремент:

```java
int a = 8;
int b = --a;
```

```java
int a = 8;
int b = a--;
```

## Операторы сравнения

Операции сравнения возвращают логическое значение:

* `true` — условие истинно
* `false` — условие ложно

| Оператор | Пример | Описание         |
| -------- | ------ | ---------------- |
| <        | a < b  | меньше           |
| >        | a > b  | больше           |
| <=       | a <= b | меньше или равно |
| >=       | a >= b | больше или равно |
| ==       | a == b | равно            |
| !=       | a != b | не равно         |

## Логические операторы

Логические операторы используются для работы с логическими значениями (`true` и `false`).  
Результатом любой логической операции всегда является значение типа `boolean`.

| Оператор | Назначение |
| -------- | ---------- |
| &&       | логическое И (AND) |
| \|\|     | логическое ИЛИ (OR) |
| !        | логическое НЕ (NOT) |

**Логическое И (`&&`)**  
Возвращает `true`, только если **оба** операнда равны `true`.

**Логическое ИЛИ (`||`)**  
Возвращает `true`, если **хотя бы один** операнд равен `true`.

**Логическое НЕ (`!`)**  
Инвертирует логическое значение: `true` становится `false`, и наоборот.

Примеры:
```java
boolean a = true;
boolean b = false;

System.out.println(a && b); // false
System.out.println(a || b); // true
System.out.println(!a);     // false
```

## Условные конструкции

Условные конструкции позволяют выполнять код **в зависимости от условия**.

### if

```java
if (условие) {
    инструкции
}
```

Пример:

```java
int num1 = 6;
int num2 = 4;

if (num1 > num2) {
    System.out.println("num1 больше num2");
}
```

### if / else

```java
if (num1 > num2) {
    System.out.println("num1 больше num2");
} else {
    System.out.println("num1 меньше или равно num2");
}
```

### else if

```java
if (num1 > num2) {
    System.out.println("num1 больше num2");
} else if (num1 < num2) {
    System.out.println("num1 меньше num2");
} else {
    System.out.println("num1 и num2 равны");
}
```

### Тернарный оператор

Короткая форма `if/else`:

```java
int z = x < y ? (x + y) : (x - y);
```

### Оператор switch

Оператор `switch` используется, когда необходимо сравнить значение одной переменной с несколькими возможными вариантами и выполнить соответствующий код.

Общая форма записи:
```java
switch (variable) {
    case value1:
        // код, если variable == value1
        break;
    case value2:
        // код, если variable == value2
        break;
    default:
        // код, если ни одно значение не совпало
}
