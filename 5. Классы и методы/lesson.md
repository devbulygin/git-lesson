# Классы и методы в Java

## 1. Что такое класс

Классы — это основа программирования на Java.
Java — объектно-ориентированный язык, а значит программа состоит из **объектов**, которые создаются на основе **классов**.

### Определение

**Класс** — это шаблон (чертёж) для создания объектов.
Он описывает:

* **состояние** объекта → через поля (переменные)
* **поведение** объекта → через методы (функции)

---

## 2. Пример простого класса

```java
public class Cat {

    String name;
    int age;

}
```

Мы создали класс `Cat` с двумя полями:

* `name` — имя кота
* `age` — возраст кота

Такие переменные называются:

* полями
* переменными экземпляра
* нестатическими полями
 У каждого созданного кота будет **своя копия** этих переменных.

---

## 3. Создание объекта

Теперь создадим объект класса `Cat`.

```java
public class FirstClass {

    public static void main(String[] args) {

        Cat barsik = new Cat();
        barsik.name = "Барсик";
        barsik.age = 3;

        System.out.println("Мы создали кота по имени "
                + barsik.name + ", его возраст - " + barsik.age);
    }
}
```

### Что происходит?

```java
Cat barsik = new Cat();
```

* `Cat` — тип
* `barsik` — имя переменной
* `new Cat()` — создание объекта

Для обращения к полям и методам используется **точечная нотация**:

```java
объект.поле
объект.метод()
```

---

# Методы

## 4. Что такое метод

**Метод** — это блок кода, который выполняет определённую задачу.

Методы позволяют:

* структурировать код
* избегать повторений
* делать программу читаемой

---

## 5. Структура метода

```java
[модификатор] тип_возврата имяМетода(параметры) {
    // тело метода
    return значение; // если тип не void
}
```

### Пример:

```java
public void sayMeow() {
    System.out.println("Мяу!");
}
```

---

## 6. Добавим методы в класс Cat

```java
public class Cat {

    String name;
    int age;

    public void sayMeow() {
        System.out.println("Мяу!");
    }

    public void jump() {
        System.out.println("Прыг-скок!");
    }
}
```

Использование:

```java
public class FirstClass {

    public static void main(String[] args) {

        Cat barsik = new Cat();
        barsik.name = "Барсик";
        barsik.age = 3;

        barsik.sayMeow();
        barsik.jump();
    }
}
```

# Конструкторы

## 7. Проблема

Сейчас можно создать кота без имени и возраста:

```java
Cat cat = new Cat();
```

Это может привести к созданию "пустых" объектов.

---

## 8. Конструктор

**Конструктор** — это специальный метод, который вызывается при создании объекта.

* Имя совпадает с именем класса
* Не имеет типа возврата

```java
public class Cat {

    String name;
    int age;

    public Cat(String name, int age) {
        this.name = name;
        this.age = age;
    }
}
```

Создание:

```java
Cat barsik = new Cat("Барсик", 5);
```

---

## 9. Ключевое слово `this`

`this` означает «этот объект».

```java
this.name = name;
this.age = age;
```

Левая часть — поле объекта
Правая часть — параметр конструктора

---

## 10. Конструктор по умолчанию

Если в классе **нет ни одного конструктора**, Java автоматически создаёт:

```java
public Cat() {
}
```

⚠ Но если вы создаёте свой конструктор с параметрами —
конструктор по умолчанию **исчезает**.

Если нужен пустой конструктор — его нужно написать вручную:

```java
public Cat() {
}
```

# ⚡ Статические элементы (`static`)

## 11. Что такое static

* Обычные поля → принадлежат объекту
* Статические поля → принадлежат классу

Создаются в **единственном экземпляре**.

---

## 12. Статическое поле

Добавим счётчик созданных котов:

```java
public class Cat {

    String name;
    int age;

    static int catCount = 0;

    public Cat(String name, int age) {
        this.name = name;
        this.age = age;
        catCount++;
    }
}
```

Использование:

```java
public class FirstClass {

    public static void main(String[] args) {

        Cat cat1 = new Cat("Барсик", 3);
        Cat cat2 = new Cat("Мурзик", 2);

        System.out.println("Создано котов: " + Cat.catCount);
    }
}
```

Обращаемся через имя класса:

```java
Cat.catCount
```

---

## 13. Статический метод

Статические методы:

* не работают с конкретным объектом
* не имеют доступа к нестатическим полям напрямую

Добавим метод:

```java
public class Cat {

    String name;
    int age;

    static int retirementAge = 15;

    public Cat(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public static void checkRetirement(Cat cat) {

        if (cat.age >= retirementAge) {
            System.out.println("Кот уже на кошачьей пенсии");
        } else {
            System.out.println("До пенсии осталось "
                    + (retirementAge - cat.age) + " лет");
        }
    }
}
```

Использование:

```java
public class FirstClass {

    public static void main(String[] args) {

        Cat barsik = new Cat("Барсик", 5);
        Cat.checkRetirement(barsik);
    }
}
```

---

## 14. Почему main — static?

```java
public static void main(String[] args)
```

Метод `main` статический, потому что:

* он вызывается без создания объекта
* JVM запускает программу через класс

---

## 15. Ограничение static

Внутри статического метода нельзя обращаться к нестатическим полям напрямую:

 Нельзя:

```java
public static void printName() {
    System.out.println(name); // ошибка
}
```

Потому что `name` принадлежит объекту, а не классу.

# 📦 Пакеты (Packages) в Java

## 1. Что такое пакет

**Пакет (package)** — это механизм группировки классов в Java.

Пакеты нужны для:

- организации структуры проекта  
- предотвращения конфликтов имён  
- управления доступом к классам  
- логического разделения кода  

Можно представить пакет как папку, в которой лежат классы.

---

## 2. Объявление пакета

Пакет указывается в самом начале файла:

```java
package animals;
````

 Важно:

* строка `package` должна быть первой (кроме комментариев)
* имя пакета должно совпадать со структурой папок

Если указан пакет:

```java
package animals.cats;
```

То файл должен лежать в папке:

```
animals/Cat.java
```

---

## 3. Импорт классов

Если класс находится в другом пакете, его нужно импортировать.

### Импорт конкретного класса:

```java
import animals.Cat;
```

### Импорт всех классов из пакета:

```java
import animals.cats.*;
```

---

## 4. Полное имя класса

У каждого класса есть **полное имя** (Fully Qualified Name):

```
animals.cats.Cat
```

Можно использовать класс без `import`, указав полное имя:

```java
animals.cats.Cat cat = new animals.cats.Cat();
```


---

## 5. Связь пакетов и модификаторов доступа

Пакеты влияют на область видимости классов и членов класса.

| Модификатор | Внутри класса | В пакете | В другом пакете     |
| ----------- | ------------- | -------- | ------------------- |
| `private`   | ✅             | ❌        | ❌                   |
| *(default)* | ✅             | ✅        | ❌                   |
| `protected` | ✅             | ✅        | ✅ (для наследников) |
| `public`    | ✅             | ✅        | ✅                   |

Пример:

```java
package animals;

public class Cat {

    String name;        // default — доступен только в пакете
    private int age;    // доступен только внутри класса
}
```

---

## 6. Зачем пакеты в больших проектах

В реальных проектах код делят по слоям:

```
com.company.project
    ├── model
    ├── service
    ├── controller
    └── util
```

### Типичная структура:

* `model` — классы данных
* `service` — бизнес-логика
* `controller` — управление
* `util` — вспомогательные классы

---

## 7. Правила именования пакетов

* только маленькие буквы
* без пробелов
* в обратном доменном стиле

Пример:

```java
package com.company.project.model;
```

Если у компании домен `company.com`, то пакет:

```
com.company.project
```
