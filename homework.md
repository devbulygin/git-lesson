## Практическое задание: Git практика

1. Создайте репозиторий `git-practice-имя-фамилия`
2. Склонируйте репозиторий
3. Добавьте `.gitignore` с исключениями и пустой `readme.md`
4. Создайте новую ветку и внесите в `readme.md` **два коммита** с вашим именем и фактом о вас
5. На GitHub в `main` в начало `readme.md` добавьте дату когда вы выполняете задание 
6. Используя **merge** слейте вашу ветку с веткой `main`
