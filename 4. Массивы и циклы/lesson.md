
# Массивы и циклы в Java

## Массивы

**Массив** — это структура данных, хранящая последовательность элементов **одного типа**.  
Массивы используются для представления списков чисел, строк и других данных как единого целого.

Особенности массивов в Java:
- все элементы одного типа
- фиксированный размер
- ссылочный тип
- доступ по индексу

---

## Объявление и инициализация массивов

### Инициализация значениями

```java
int[] numbers = {1, 2, 3};
String[] cars = {"kia", "bmw", "ford"};
````

Тип массива записывается как `тип[]`.

> Переменные массивов принято называть во **множественном числе** — это улучшает читаемость кода.

---

### Создание массива заданного размера

Если значения неизвестны заранее:

```java
int[] numbers = new int[3];
String[] cars = new String[3];
```

Размер массива задаётся при создании и **не может быть изменён**.

---

### Пустой массив

```java
int[] empty = new int[0];
```

Такой массив допустим, но не содержит элементов.

---

### `NullPointerException`

```java
String[] cars = new String[2];
cars[0].length(); // ошибка
```

Причина: элемент равен `null`.

---



## Вывод массивов

Прямой вывод массива:

```java
System.out.println(cars);
```

Результат — служебная информация, а не элементы массива.

Правильный вывод:

```java
System.out.println(Arrays.toString(cars));
```

Для вложенных массивов:

```java
System.out.println(Arrays.deepToString(matrix));
```

---

## Доступ к элементам массива

Элементы массива упорядочены и имеют индексы.
Индексация начинается с **0**.

```java
String[] animals = {"cats", "dogs", "birds"};

animals[0]; // "cats"
animals[1]; // "dogs"
animals[2]; // "birds"
```

Размер массива:

```java
animals.length; // 3
```

Последний индекс всегда равен `length - 1`.

---

## Значения по умолчанию

Созданный, но не инициализированный массив заполняется значениями по умолчанию:

| Тип     | Значение |
| ------- | -------- |
| int     | 0        |
| double  | 0.0      |
| boolean | false    |
| String  | null     |

```java
String[] cars = new String[2];
System.out.println(cars[0]); // null
```

---

## Изменение элементов массива

```java
animals[0] = "horses";
```

Попытка обратиться к несуществующему индексу приводит к ошибке:

```text
ArrayIndexOutOfBoundsException
```

---

## Вложенные массивы

Массивы могут содержать другие массивы.

```java
int[][] weather = {
    {14, 15},
    {17, 18},
    {13, 14}
};
```

Доступ к элементам:

```java
weather[0];    // [14, 15]
weather[0][1]; // 15
```

Создание и заполнение вручную:

```java
int[][] weather = new int[3][2];

weather[0][0] = 14;
weather[0][1] = 15;
```

Вложенность не ограничена:

```java
int[][][] data = {{{1,2},{3,4}}, {{5,6},{7,8}}};
```

## Циклы

Циклы используются для многократного выполнения кода, чаще всего — для обработки массивов.

---

## Цикл `for`

Основной цикл для перебора массива.

```java
for (int i = 0; i < names.length; i++) {
    System.out.println(names[i]);
}
```

Составные части:

* инициализация счётчика
* условие продолжения
* изменение счётчика

---

### Обход в обратном порядке

```java
for (int i = names.length - 1; i >= 0; i--) {
    System.out.println(names[i]);
}
```
## Изменение массива в цикле

Изменять элементы можно только через индекс:

```java
for (int i = 0; i < numbers.length; i++) {
    numbers[i] *= 2;
}
```

В `for-each` изменение элемента не влияет на массив.

---



## Цикл `for-each`

Упрощённый цикл для перебора элементов без индексов.

```java
for (String name : names) {
    System.out.println(name);
}
```

Подходит для:

* чтения элементов
* агрегации

Не подходит, если:

* нужен индекс
* требуется обратный порядок
* нужно изменять массив

---



## Цикл `while`

Цикл `while` выполняется **пока условие истинно**.
Подходит, когда количество итераций заранее неизвестно.

```java
int i = 0;

while (i < 3) {
    System.out.println(i);
    i++;
}
```

Важно:

* условие проверяется **до каждой итерации**
* счётчик нужно изменять вручную

---

### `while` и массивы

```java
String[] names = {"petya", "vasya", "evgeny"};

int i = 0;
while (i < names.length) {
    System.out.println(names[i]);
    i++;
}
```

---

## Цикл `do-while`

Тело цикла выполняется **минимум один раз**, даже если условие ложно.

```java
int i = 0;

do {
    System.out.println(i);
    i++;
} while (i < 0);
```

---

## Агрегация

**Агрегация** — вычисление одного результата на основе всех элементов массива
(сумма, максимум, минимум и т.д.).

---

### Поиск максимального значения

```java
public static Integer calculateMax(int[] numbers) {
    if (numbers.length == 0) {
        return null;
    }

    int max = numbers[0];

    for (int i = 1; i < numbers.length; i++) {
        if (numbers[i] > max) {
            max = numbers[i];
        }
    }

    return max;
}
```

---

### Сумма элементов массива

```java
public static int calculateSum(int[] numbers) {
    int sum = 0;

    for (int number : numbers) {
        sum += number;
    }

    return sum;
}
```

Сумма элементов пустого массива равна `0`.

---

## Нейтральный элемент операции

Любая агрегация начинается с начального значения.

* сложение → `0`
* умножение → `1`
* строки → `""`

Неверно выбранное начальное значение приводит к ошибочному результату.

---

## Управляющие инструкции

### `break`

Прерывает выполнение цикла.

```java
for (String value : values) {
    if (value.equals("stop")) {
        break;
    }
    System.out.println(value);
}
```

---

### `continue`

Пропускает текущую итерацию цикла.

```java
for (String value : values) {
    if (!value.equals("stop")) {
        continue;
    }
    System.out.println(value);
}
```

## Частые ошибки новичков

### `length` vs `length()`

```java
array.length     // массив
string.length()  // строка
```

---

### Ошибка границ массива

```java
for (int i = 0; i <= array.length; i++) // ошибка
```

Правильно:

```java
i < array.length
```
